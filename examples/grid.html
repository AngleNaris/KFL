Grid

One manifest declares three breakpoints and every region's span. From it, generate.mjs writes the page's CSS and audit.mjs measures the rendered page against it. Toggle the overlay to see the twelve tracks under this page.

Breakpoints

Four columns on phones so pairs can sit side by side; eight on tablets, where the frame stops at 800px so text cannot outgrow its measure; twelve from 1120px up, where a label and an aside can flank the text. Each step is a deliberate re-composition, not a squeeze.

Rules

  • Columns are equal tracks; gutters and margins come from the manifest.
  • Cap prose measure within its region; the page frame follows the layout and content.

Page anatomy

Every page in this kit is built from the same named regions. The title and lede start on the fourth column, the reading edge the section prose shares, and each section repeats the label–text–aside–body pattern with its heading in the first three columns. That shared rhythm is what lets the eye rest.

Region spans

A section’s body text takes the middle six columns at desktop; the aside takes three; the body below takes nine and shares the text’s start edge. Halves, thirds and quarters divide the frame without ever leaving a fractional track.

Rules

  • Spans are declared once in the manifest.
  • A region’s start can pin to a column; flow fills the rest.

Subgrid

When inner blocks must align with the columns of the grid around them, the row inside uses grid-template-columns: subgrid and borrows those tracks. Content that needs no shared edge uses an independent local layout with its own gaps.

Rules

  • Share tracks only when contents must align across regions.
  • A nested equal-track grid declares data-grid-columns; an independent one declares data-grid="local".

The audit loop

Generation and audit share one manifest resolver for consistent inheritance. The grid audit measures annotated regions in Chromium against configured tracks and tolerance. The optional surface audit reports selected geometry, text and target findings; neither tool replaces visual approval or behavior verification.

Commands

  • node tools/grid/generate.mjs manifest.json outdir
  • node tools/grid/audit.mjs --manifest m.json --html page.html
  • node tools/surface/audit.mjs --html page.html
$ node tools/grid/audit.mjs --manifest examples/grid/kfl.manifest.json --html examples/components.html
$ node tools/surface/audit.mjs --html examples/components.html --geometry square

Exit 0 means the configured checks passed, 1 lists violations, 2 means the page was not tested. Run them yourself; this page records no results.
