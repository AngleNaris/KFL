Grid

01 · Foundation

Breakpoints

Four columns on phones so pairs can sit side by side; eight on tablets, where the frame stops at 800px so text cannot outgrow its measure; twelve from 1120px up, where a label and an aside can flank the text. Each step is a deliberate re-composition, not a squeeze.

Rules

  • Columns are equal tracks; gutters and margins come from the manifest.
  • The container never outruns 75ch of body text.

02 · Regions

Page anatomy

Every page in this kit is built from the same named regions. The kicker hangs in the first three columns, the title and lede share the fourth column's edge, and each section repeats the label–text–aside–body pattern. That shared rhythm is what lets the eye rest.

03 · Ratios

Region spans

A section’s body text takes the middle six columns at desktop; the aside takes three; the body below takes nine and shares the text’s start edge. Halves, thirds and quarters divide the frame without ever leaving a fractional track.

Rules

  • Spans are declared once in the manifest.
  • A region’s start can pin to a column; flow fills the rest.

04 · Nesting

Subgrid

A card grid that spans the whole frame still aligns its inner blocks to the page columns: the row inside uses grid-template-columns: subgrid. Inner content never invents its own gutter or its own rhythm.

Rules

  • Nested grids inherit the parent’s tracks.
  • Independent nested grids are the bug the audit rejects.

05 · Verify

The audit loop

Generation and audit share one manifest resolver for consistent inheritance. The grid audit measures annotated regions in Chromium against configured tracks and tolerance. The optional surface audit reports selected geometry, text and target findings; neither tool replaces visual approval or behavior verification.

Commands

  • node tools/grid/generate.mjs manifest.json outdir
  • node tools/grid/audit.mjs --manifest m.json --html page.html
  • node tools/surface/audit.mjs --html page.html
$ node tools/grid/audit.mjs --manifest examples/grid/kfl.manifest.json --html examples/components.html
grid-audit ok — 4/8/12 columns, 14 regions on their tracks, margins 16/32/48 within tolerance

$ node tools/surface/audit.mjs --html examples/components.html
surface-audit ok — 0 rounded corners, 0 pills, smallest text 12px, smallest target 40px

Both audits run headless and cross-platform; they reuse whatever Chromium Playwright already has cached.
